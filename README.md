  4. **문제 4: register()와 delete()함수가 사용자가 입력한 숫자와 실제 적용된 숫자의 괴리를 정확히 출력하지 못함** 
     * **원인: 기존코드에서는 잘못된 입력이 발생하면 해당 입력은 무시하고 넘어감. 이 경우 기존에 등록(삭제)할 인원수보다 적은 인원이 적용되지만 처음 입력한 수만큼 적용되었다고 출력되는 문제가 있었음** 
     * **해결: register()에서는 'while True'를 이용하여 '등록할 인원수'만큼 등록하도록 코드를 수정함. 이 경우 등록할 인원수 만큼 등록하지 못하면 코드에서 탈출이 제한되지만 입력 완료후 삭제할 수 있기 때문에 문제가 되지 않음. delete()에서는 실제 삭제된 인원수를 출력하도록 코드를 수정함**
